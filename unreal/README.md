# DOOMED — version Unreal Engine 5.8

Le jeu compilé est distribué en archive dans les **Releases** du dépôt (pas dans ce dossier, pour garder le dépôt léger) :

**[Télécharger DOOMED pour Windows (archive .zip, 200 Mo)](https://github.com/thibaud200/DOOMED/releases/latest)**

1. Télécharger `DOOMED_Unreal_Windows.zip` dans la dernière Release.
2. Le décompresser (environ 300 Mo).
3. Lancer `DOOMED/Doom.exe`.

Configuration : Windows 64 bits, carte graphique compatible DirectX 12.

Contenu : 95 niveaux (intérieurs et extérieurs), menu de démarrage, pause (Échap ou P), sauvegarde en 5 emplacements.
Les commandes sont dans le [README principal](../README.md#commandes).
